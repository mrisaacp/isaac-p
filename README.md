# isaac-p

Personal website for Isaac Pounders. A plain static site (HTML and CSS, no build step).

## Files

- `index.html` holds all of the content.
- `styles.css` holds the styling, including automatic dark mode.

## Run locally

Open `index.html` in a browser, or run `python3 -m http.server` in this folder and visit http://localhost:8000.

## Publish with GitHub Pages

In the repository, go to Settings, then Pages, set the source to "Deploy from a branch", choose `main` and `/ (root)`, and save. The site will be live at https://mrisaacp.github.io/isaac-p/ after a minute or two.
